# Douyin Learning Workbench · 抖音学习工作台

本地运行的非商业学习原型：搜索视频、读取评论、管理数据，并同步查看执行浏览器画面。

## 同事首次使用（Windows）

1. 下载本仓库 ZIP 并完整解压，先安装 Python 3.12。
2. 双击 `start.cmd`。第一次会联网创建 Python 环境并安装依赖。
3. 在项目文件夹打开 PowerShell，执行 `./install-browser.ps1` 安装 Chromium。
4. 打开 http://127.0.0.1:8765，点顶部 **新手指南**。
5. 到 **关注与私信 → 打开浏览器登录**，在工具打开的独立抖音窗口中使用你自己的账号登录。
6. 回到 **新建搜索** 输入关键词，点击 **开始网页读取**。

结束时双击 `stop.cmd`。数据和登录状态保留在你自己的电脑上，账号过期时需要重新登录。首次下载没有原作者的账号或历史数据。

**普通 Chrome／Edge 已登录，不等于工具浏览器已登录。** 右侧是同步预览；登录、验证码与手动点击请使用“操作浏览器”打开的原窗口。“本地服务已连接”仅表示本地后端可用。

## 视频信息与排序

视频行显示点赞、评论、收藏、分享、播放、弹幕，详情可查看作者、发布时间、时长与读取时间。支持 12 种排序及升降序，缺失值排末尾。旧记录可单条或批量「补充视频信息」，进度及结果保存在新任务。

真实页面已验证点赞、评论、收藏、分享；播放量等未公开时显示 `—`，页面约数显示 `≈`，不会将缺失当成 0。

## 功能与实际边界

- 关键词搜索：每次最多 100 个视频，数量与相关性取决于平台实际页面。
- 评论与回复：按批读取，每批最多 100 条；已存数据分页查看、用户去重。无法保证与平台显示的总评论数相等。
- 数据管理：单列列表、长文省略、按需选择、CSV／JSON 导出和删除。
- 浏览器同步画面：只读预览，可放大，登录验证需要本人操作独立窗口。
- 关注／私信：单对象流程已验证，但每个同事必须核对自己的账号、获准对象与完整内容；不确定时先核对，不重复执行。
- 批量视频下载：本地示例已验证，真实抖音下载仍待验证。无正常下载入口或遇访问限制时停止并显示原因。

请勿将 `learning_data/`、`browser_data/`、`.env`、登录会话、Token、真实用户数据或诊断截图提交到 GitHub。本项目不提供验证码或访问限制绕过功能。

## 修改前端

仓库包含可直接运行的界面产物，普通使用无需 Node.js。修改前端时安装 Node.js（建议 22），进入 `webui` 执行 `npm ci` 和 `npm run build`，随后刷新工作台。

Python 后端为 FastAPI + SQLite，网页自动化使用 Playwright。当前便捷脚本面向 Windows；Mac／Linux 需自行配置环境和启动方式。
