# 抖音学习工作台

首次使用请看 [新手使用指南](docs/新手使用指南.md)。工作台顶部“本地服务已连接”左侧也有“新手指南”，重点说明独立浏览器登录、验证码及首次搜索。

本地可运行的非商业学习原型，复用 MediaCrawler 的 React 界面组件和构建环境，沿用 Python + FastAPI，并用 SQLite 保存结果。

**视频信息与排序：**视频行显示点赞、评论、收藏、分享、播放、弹幕；详情增加作者、发布时间、时长、视频编号与信息读取时间。支持这些指标以及标题、作者、搜索顺序排序，升降序均将缺失值放在末尾。旧记录可单条或批量“补充视频信息”，结果保存到新任务。真实页面已验证点赞、评论、收藏、分享和作者读取；播放、弹幕等未公开时保持缺失，不保证全量字段可用。见 [视频指标说明](docs/数据浏览操作说明.md#视频信息与排序)。

**浏览器画面更新：**任务执行时可在工作台右侧查看工具浏览器的同步画面，支持放大、收起和切到原浏览器操作。页面整体缩小间距、精简重复说明；宽度不足时自动上下排列。此处是只读同步画面，登录/验证码仍在原浏览器完成，详见 [操作说明](docs/数据浏览操作说明.md)。

**界面更新：**参考原版电商 Agent 的蓝白工作台。四张统计卡可点击，和侧栏共用“累计任务、已存视频、去重用户、已存评论”四个入口。按任务时间、关键词和视频查找，进入视频后单独查看评论，点击作者打开用户侧栏。使用方法见 [数据浏览操作说明](docs/数据浏览操作说明.md)。

**当前可用：关键词搜索最多 100 个真实视频、点击视频读取评论及用户信息、去重保存、导入导出和日志。最新“晒猫”实测取得 67 条带时长的视频卡片；不足 100 条时保留部分结果。选择其中一个视频，已验证主评论 100 → 200 条、200 位去重用户、翻页、刷新恢复与导出，其中 195 条含图片，明确标为图片内容未读取。单对象关注/私信已在用户指定账号和对象上分别完成一次真实验证：关注显示“相互关注”，消息“测试”刷新后可核对。具体条件与边界见 [账号操作说明](docs/账号操作说明.md)。**

本轮修复搜索结果混入图文帖、相关搜索卡片的问题：页面提供搜索卡片时，只接收明确展示视频时长的卡片，未知类型跳过。旧版“露营”等 100 条结果属于历史读取记录，当时未严格验证内容类型，不能作为新版“100 条纯视频”的保证。旧任务数据保留，详见验证记录。

评论现支持 **每批 100 条、点击继续、上一页／下一页与刷新恢复**。本次真实视频累计保存 **534 条主评论记录、3 条所选讨论回复、514 位去重用户**，已实测识别页面结束提示并显示“主评论已到底”。这不表示已获取全部回复或平台总评论数。

**本次更新：**每条主评论下可点“读取回复”，回复独立按每批最多 100 条读取，显示回复作者与主页；主评论页码保持不变。已在真实视频验证一条讨论的 3 条回复，并连续读取主评论经过 300、400、500 条。右侧“导出本视频评论（含已存回复）”可直接下载 JSON。进度、暂停和继续同时适用于主评论及回复。

**最新实测：**另一条“男友穿搭”视频讨论已补齐 **148 条回复（146 条文字 + 2 条纯表情）**，按 100 / 48 两页显示，所选讨论已确认读完。新增表情显示为 `[看]`、`[流泪]`；原 246 条评论记录保持不变。旧版未支持任务可补读表情和图片标识，完成后禁止重复请求。详情见 `docs/EVIDENCE.md`，本地 62 项测试通过。

**图片评论标识已在真实视频验证。**本轮 200 条主评论中，195 条保存图片标识与作者，其中 3 条为纯图片占位；其余含图片评论保留文字并提示未读取的图片数量。只保存图片存在的标识，不下载、展示或解析原图。已适配本次看到的正文外图片容器；图片回复共用规则，但其完整流程当前仍以本地夹具验证为主，不能据此承诺所有页面结构均可识别。

**批量操作更新（2026-09-10）：**各数据列表先勾选，再导出 CSV / JSON 或批量删除；逐条删除图标已移除。视频支持通过平台正常下载入口逐条下载并打包 ZIP，逐条显示结果与受阻原因。本地下载样例已验证，真实抖音下载仍待验证。详见 [数据浏览操作说明](docs/数据浏览操作说明.md)。

**搜索优化（2026-09-10）：**默认确认“视频”分类后读取，支持动态列表滚动；连续 30 秒无新增与明确读到页尾分别显示。最新“广州 领养 猫”实测保存 64 条后标为加载停滞，未承诺 100 条或全部主题相关。

## 1. 启动与停止

1. 在本文件所在文件夹双击 **start.cmd**。
2. 浏览器打开 **http://127.0.0.1:8765**。
3. 结束时双击 **stop.cmd**。会关闭本工具的独立浏览器，数据会保留。

重复启动会复用已经运行的本项目服务。当前电脑的依赖已准备好。

如果搬到另一台电脑：先安装 Python 3.12（或更高版本），首次启动会创建虚拟环境并安装 `requirements-learning.txt`。发行包带有已构建界面；只有重新构建界面才需要 Node.js。网页读取还需要在 PowerShell 中执行 `./install-browser.ps1` 安装 Chromium。

端口冲突时可运行 `./start.ps1 -Port 8766`，随后使用输出的新地址。同一项目只运行一个实例；项目已运行时指定其他端口仍会复用原实例，需要先停止才能换端口。调试时可加 `-NoBrowser` 避免自动打开页面。

## 2. 开始搜索

1. 输入你需要的关键词，点击 **开始网页读取**。
2. 在工具打开的浏览器中本人完成必要的登录或验证。
3. 从视频列表选择视频，查看评论、用户和主页链接。
4. 点击 **下一批 100 条** 继续读取，或 **导出结果** 保存 JSON。

界面已移除模拟搜索、模拟关注、模拟私信与模拟记录。日常任务、日志和统计仅包含网页读取及本地导入；旧模拟记录没有物理删除，开发用的内部示例与回归测试仍保留。关注/私信标记为“已接入 · 待真实验证”，不会把本地测试当成真实成功。

## 3. 导入已有数据

点击 **导入 MediaCrawler JSON**，选择有权使用的 JSON 数组文件，最多 500 条、2 MB。

兼容的扁平字段：

- 视频：`aweme_id`、`title` 或 `desc`；可选 `user_id`、`nickname`。
- 评论：`aweme_id`、`comment_id`、`user_id`（或 `sec_uid`）、`content`；可选 `nickname`。

导入数据标记为“本地导入”，不代表已经在真实平台验证。真实关注与私信执行尚待验证；新确认入口见左侧“关注与私信”。

本工具导出的任务 JSON 是带任务信息的对象，**不是 MediaCrawler 扁平数组，不能原样再次导入**。每个任务保留当次数据快照，后续导入同一记录的新内容不会改写旧任务导出。

## 4. 尝试真实网页读取

新版交互：**输入关键词 → 最多 100 条视频列表 → 点击一个视频 → 查看该视频的评论、用户昵称及主页链接**。搜索顺序是此次页面展示顺序，不是全平台热度排名。不会在搜索阶段批量读取所有视频评论。

本次已在工作台实测完整流程：“露营”得到 100 条视频，点击第 1 条显示 4 条评论和 4 位用户。评论保存为独立的“读取指定视频评论”任务；需要导出评论时，在任务选择框选该任务后点击“导出结果”。搜索任务的导出保存视频列表。

1. 填写关键词，点击 **开始网页读取**。
2. 工具打开独立 Chromium 浏览器；请在这个浏览器中本人完成必要登录或验证。
3. 遇到登录、验证、页面结构不匹配时，任务会停止并显示原因，不会自动重试。
4. 本人处理页面后点击 **继续读取当前搜索页**，保持关键词与浏览器搜索页一致。搜索结束后，在“视频”标签点击任一视频，右侧先收集并显示最多 **100 条主评论**与对应用户。
5. 点击 **下一批 100 条** 才会继续采集；**上一页／下一页** 浏览已保存的评论，不重复访问平台。当前页最多显示 100 条，累计数量另行显示。
6. 若只读到部分评论，处理页面后点 **处理页面后继续本批**，继续补齐本页。检测到登录、验证或加载停滞会暂停，保留已经写入的内容；也可主动点 **暂停读取**。
7. 在需要查看的主评论下点击 **读取回复**；查看已存回复可展开本地分组，继续读取回复每次最多新增 100 条。无可识别入口或加载失败时显示部分结果，不能据此断言没有回复。主评论到末尾后，仍可读取某条评论的回复。
8. 刷新后再次进入“视频”标签可恢复所选视频的评论任务。也可从任务列表选“读取指定视频评论”，再进入“视频”标签接着读取。只有评论区明确提示没有更多内容时，才显示 **主评论已到底**；它不表示所有回复均已采集。导出按钮包含本视频累计保存的主评论、回复、用户及状态。

回复结束状态分三种：**该评论回复已读完**表示当前可识别讨论已读完；**已到页尾 · 有未支持内容**会显示未保存数量并停止续读；**核对页面后继续回复**表示加载受阻或结束状态不确定，核对页面后才继续。后两种均保留已有结果，不会伪装成完整采集。

旧版停止的讨论可点 **补读表情与图片标识**或**补读图片标识**：例如页面表情图片的名称为 `[看]`，就保存并显示 `[看]`，同时保留作者。不会下载表情图片。图片仅保存占位和作者，结束时保留不完整状态；无名称表情或不能可靠定位的图片仍会显示未支持。同版本到页尾后禁止反复补读。已完成的历史任务不自动重读或改写；主评论的纯表情与混合图文完整还原仍未支持。

新版支持地址带 `modal_id` 的搜索页视频弹窗。也可在 **测试视频链接** 中粘贴地址，点击 **按视频链接读取**，直接打开对应视频详情。该入口仅在后端已更新时显示。若首次任务因评论“加载中”暂停，等本人看到评论后点击 **读取当前视频评论**。当前已在指定视频上验证真实读取与保存。

读取范围：每次搜索最多 100 个去重视频，按页面顺序保存；通过普通页面滚动加载更多，限制运行时间和无新增结果的次数。未达到 100 条时保留实际结果并显示“部分结果”，不伪装成已满 100 条。评论与回复分别按每批最多 100 条读取，按首次读取顺序累积保存并去重。**支持可识别的文字主评论和用户选择展开的讨论回复；未选择的讨论、纯图片及其他未识别内容不会自动补齐，因此不能承诺等于平台显示的总评论数。**不调用非公开接口，不使用隐身脚本或代理绕过限制。

网页 DOM 结构会变化，浏览器测试夹具通过不代表抖音现场读取通过。首轮实测状态为 **待核对页面**，尚未取得真实视频或用户数据。

后续现场适配已完成：用户指定的视频 `7594819804352040192` 成功读取 1 个视频、14 条评论、14 位用户，连续两次读取的记录 ID 相同，数据库数量未增加，导出核对通过。“露营”搜索随后已实测得到 100 个去重视频。其他关键词、其他账号与平台改版仍可能产生不同结果。

后续诊断已确认搜索页标题、导航与分类可以加载，但暂停时没有展示视频结果文字。未检测到明确登录或验证提示，具体原因仍需本人核对独立浏览器。不会把页面空白当成搜索成功。

用户随后反馈：此前有图形验证码，之后已显示视频。现有检测未识别这次图形验证码，因此验证检测仍不完整。本人看到验证时应先停止任务、手动处理；处理后可打开一个测试视频并展开评论，使用“读取当前视频评论”，避免重新搜索。

暂停时会在本机 `learning_data/diagnostics/` 保存页面文字 JSON，并尝试截图；截图超时也保留文字诊断。截图成功时，任务详情显示查看链接。诊断内容可能包含页面个人信息，仅用于本机排错，不放入交付压缩包。

评论没有从页面取得平台评论 ID 时，使用“视频 + 用户 + 文本”生成带 `dom-` 前缀的本地标识；相同用户在同一视频重复发表完全相同的文字会被合并。这不是平台原始评论 ID。

回复标识以 `dom-reply-` 开头，额外包含所属主评论 ID；导出字段 `kind=reply`、`parent_comment_id` 和 `reply_rank` 分别表示回复类型、所属讨论与读取顺序。同一作者在不同讨论下的同文回复分别保存。新版读取会排除回复区，避免把页面自动展示的回复混算为主评论；旧版本的任务快照保留原样。

纯表情回复额外导出 `content_type=emoji` 和 `emoji_labels`，`content` 为按顺序拼接的表情名称。表情 ID 与恰好输入相同方括号文字的评论区分；同一作者在同一讨论重复发完全相同的表情仍会合并。剩余任务与分工见 `docs/REMAINING_TASKS.md`。

图片记录导出 `content_status=image_not_read`、`image_count` 与 `image_fingerprints`；纯图片的 `content_type=image_placeholder`，`content` 是占位提示，不是图片文字。图片地址只用于在内存里生成摘要，原地址不写入结果；去重忽略地址查询参数。同一作者在同一讨论反复发送相同图片会合并，不同图片共用同一路径时也可能合并，这不是平台原始评论 ID。

## 5. 状态怎么看

| 状态 | 含义与下一步 |
|---|---|
| 成功 | 对应来源的读取或文件导入完成；以来源标签区分 |
| 待登录／待验证 | 需要本人检查独立浏览器，再创建新任务 |
| 待核对页面 | 没有识别到预期元素；可能是加载、登录或结构变化，需要进一步核对 |
| 部分结果 | 保留已找到的视频或评论；加载受阻可核对后继续，已到页尾但有未支持内容则停止续读，详见任务提示 |
| 失败 | 读取出错或超时，查看日志；不会自动重试 |
| 中断 · 需核对 | 服务执行中被停止，重启后保留该状态，未自动恢复操作 |
| 已取消 | 不再写入本任务后续结果；正在进行的页面请求可能需要等待超时 |
| 待接入 | 单对象确认流程与严格网页适配已接入；真实账号执行尚待登录和指定对象验证 |

## 6. 数据与代码位置

- `learning_data/learning.db`：任务、用户、评论、模拟动作和日志。
- `learning_data/browser/`：独立浏览器的本地登录会话。不要分享此目录。
- `learning_data/server.err.log`：启动或运行问题排查日志。
- `learning_data/diagnostics/`：暂停任务的页面诊断，文件名对应任务 ID。
- `learning/`：本次增加的 Python 适配层。
- `learning/selectors.json`：视频卡片、评论昵称与正文的页面选择规则，每次读取时加载；改版排错时可调整，无需重启浏览器。规则需根据实际页面核验。
- `webui/src/components/learning/LearningPanel.tsx`：学习版界面。
- `tests_learning/`：适配层测试，不会通过测试执行真实私信。
- `docs/EVIDENCE.md`：验证结果和仍未接入的能力。

需要备份数据时，先停止服务并关闭独立浏览器，再备份 `learning_data`；该文件夹可能含登录状态，不要当普通代码发给别人。

修改前端后，在 `webui` 目录执行 `npm ci`（首次）和 `npm run build`，再重启服务。修改 Python 代码后重启服务即可。日常修改关键词和视频链接直接在界面操作。
