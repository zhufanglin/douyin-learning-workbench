# 需求用户

在左侧“数据与任务”点击“需求用户”。这里只整理已保存评论及其用户，不重新访问抖音。

- 每位用户合并显示，保留不同留言。缺少用户ID的评论不会强行合并。
- 用“业务目标”筛选关联采集任务；旧任务没有配置时在“全部业务与历史记录”中查看。
- 用“昵称或评论”搜索，展示匹配的留言；清空恢复全部。
- 点击用户主页、来源内容或任务时间可以回看。评论未提供时间时显示“未提供”。
- 每页20位用户；每人先展示3条留言，点击展开更多。刷新会读取最新保存结果。

现已支持本地规则初判与人工改判。未选择分析业务、未分析或旧分析失效的评论仍为“待判断”。配置筛选依据历史任务快照；不会对没有业务配置的历史记录自动补配目标。

## 规则初判与人工判断

1. 在“新建搜索”的业务配置中填写需求词、广告词、排除词，每行一个短语，每类最多50个。原有目标、纳入和排除条件文本仍供人工参考，不自动转换为规则。
2. 回到“需求用户”，选择“分析业务”，点击“分析已存评论”。分析对全部已存评论执行，与当前页面来源筛选独立；同一批评论可用于不同业务，各自保存判断。
3. 需求词命中为可能需求；广告词或排除词命中分别给出推广广告或无关的规则初判。冲突、部分否定表达、无命中均待判断。不是语义模型，不保证理解反讽、复杂否定和上下文；明确需求只能人工确认。
4. 每条评论显示命中词和原因，可展开“人工判断”，选择类别并填写依据后保存。也可恢复规则初判。
5. 修改配置或原话后旧结果提示重新分析；重复分析未变化记录保留人工判断，变化记录重新初判。新增评论需再次分析。可用判断类别筛选结果。

分析在本机完成，不调用外部模型，不触发抖音操作。未提供时间或联系方式不推断填充。

## 自定义字段与时间筛选

在业务配置中点击“添加需求字段”，填写字段名和匹配短语（每行一个）。例如规格可填XL、小号；服务项目可填安装、维修。它们仅是示例，系统不预置行业字段。最多10个字段，每个字段50条短语。保存配置后，回需求用户重新分析。

每条留言下面显示字段原文提及，未命中显示“—”。字段不是推断结果：例如“不要XL”中的XL也只表示提及，不代表用户选择XL。按配置短语匹配，不自动理解预算、地点或规格。原始评论就是需求描述的依据。

展开“字段与评论时间筛选”：可选择字段、有提及或未提及/未分析，或输入字段值的一部分。字段筛选只在当前分析业务下生效，过期结果不参与值匹配。

日期按本机时区，开始与结束日均包含；设置范围排除缺失时间的评论。选择“时间未提供”时停用日期范围。不会使用任务采集时间冒充评论时间。清除按钮恢复这些筛选。
