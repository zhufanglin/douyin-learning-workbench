# 新手使用指南

在工作台顶部，点击“本地服务已连接”左侧的 **新手指南** 即可随时查看。

## 先区分两个窗口

| 窗口 | 用途 |
| --- | --- |
| 工作台 | 发起任务、查看进度、管理结果；右侧仅显示同步画面 |
| 独立抖音浏览器 | 登录、输入、本人完成验证码 |

**本地服务已连接不代表抖音已登录。** 同事需用自己的账号，查看指南不会启动任务。

```mermaid
flowchart LR
  A[启动工作台] --> B[打开浏览器登录]
  B --> C[本人完成抖音登录]
  C --> D[搜索关键词]
  D --> E[查看视频与评论]
  E --> F[选择与导出]
```

## 1. 第一次启动

1. Windows 电脑先安装 Python 3.12，再双击项目中的 start.cmd。首次启动会安装依赖，请等待窗口提示。
2. 在项目目录用 PowerShell 执行 ./install-browser.ps1，安装网页读取所需的 Chromium（首次需要）。
3. 打开 http://127.0.0.1:8765。看到“本地服务已连接”表示工作台服务正常，不代表已登录抖音。结束使用可双击 stop.cmd。

## 2. 登录抖音：先认准窗口

1. 首次使用，进入左侧“关注与私信”，点“打开浏览器登录”。这一步只打开抖音，不会关注或发送消息。
2. 在弹出的独立抖音浏览器中，用你自己的账号完成扫码或其他登录验证。不要在工作台右侧的同步画面上扫码操作或点击输入。
3. 回到工作台，点“我已登录，读取本人账号”，核对显示的抖音号。若仍要求登录，请回独立窗口检查是否真正完成。
4. 已有执行画面时，也可点画面下方“操作浏览器”切回原窗口。平时 Chrome、Edge 的登录与本工具独立；登录状态保存在本机，过期后需重新登录。

## 3. 第一次搜索与验证码

1. 进入“新建搜索”，输入关键词，点“开始网页读取”。正常会出现读取状态、数量进度，右侧显示浏览器同步画面。
2. 看到登录或验证码时先暂停任务，点“操作浏览器”，本人完成页面要求。不要连续点击开始，也不要新建重复任务。
3. 处理完成后，展开“辅助读取与导入”，点“继续读取当前搜索页”；工作台关键词须与抖音搜索页一致。
4. 完成后点“查看本次搜索结果”。每次最多 100 个视频，数量不足时会保留已取得的结果；平台可能不再提供更多或返回弱相关内容。

## 4. 查看视频、评论与用户

1. 点击视频行进入详情，有已存评论时先展示历史记录；没有时点“读取此视频评论”。长标题悬停可看全文。
2. 主评论每批最多 100 条；“下一批 100 条”继续读取，“上一页／下一页”只翻看已保存内容。受阻时处理页面后继续本批。
3. 评论下的“读取回复”单独读取该讨论。主评论已到底不等于全部回复已读完；图片可能仅有标识。
4. 点击评论作者查看用户详情；长评论点“展开全文”。已存视频、去重用户、已存评论可分别按任务或视频筛选。

## 5. 选择、导出、下载与删除

1. 先点列表上方“选择”，再勾选记录或全选；点“取消选择”清空并隐藏勾选框，切换筛选或分页也会退出选择模式。
2. 导出 CSV／JSON 保存已选数据。视频列表还可“批量下载视频”，在“视频下载”中查看逐条状态；真实抖音下载仍待验证，没有正常下载入口时会显示原因。
3. 删除前核对确认窗口中的记录和影响范围。运行中的任务需先暂停，删除功能没有回收站，重要数据先导出。

视频列表上方可选择点赞、评论、收藏、分享、播放、弹幕等排序和升降序。旧视频信息不全时，点击“补充本任务视频信息”，或先“选择”并勾选后点击“补充视频信息”；新任务显示读取进度和结果。缺失指标显示 `—` 且排末尾，页面约数显示 `≈`，播放量等可能不公开。详细规则见 [视频指标说明](数据浏览操作说明.md#视频信息与排序)。

## 6. 关注与私信

1. 先读取本人账号，再填写获准测试的用户主页，选择关注或私信；私信要填写完整消息。
2. 点“核对账号与操作条件”仅预检查。仔细核对后，再在确认区执行一次；登录成功不代表目标允许接收私信。
3. 到“操作记录”查看结果。遇到结果不确定，先只读核对，避免重复关注或重复发送。同事需要自己的测试授权，不能沿用别人的授权。

## 常见问题

### “操作浏览器”灰色或没有画面？

先到“关注与私信”点击“打开浏览器登录”。如果缺少浏览器，运行项目的 install-browser.ps1；画面延迟时以独立浏览器和任务日志为准。

### 关闭后还要重新登录吗？

正常停止会保留本机数据与登录目录。账号过期、主动退出或清除登录目录后，需要重新登录。

### 同事下载项目后为什么看不到我的数据？

交付包不带你的任务数据库和登录会话。同事首次使用应自行登录，不要把 learning_data、登录目录或验证码截图上传到 GitHub。

### 失败了能一直点重试吗？

先看“任务日志”和独立浏览器，确认登录、验证或页面加载问题。关注、私信结果不确定时只核对记录，不重复执行。


## 选择搜索方式

新建搜索时可选“先找视频，按需读取评论”（默认，较快），或“搜索后，逐个读取评论”（耗时更长）。第一种保存视频后自行选择读取评论；第二种依次读取本次找到的视频，每个首批最多100条，更多继续读取，不保证全部评论。两种方式遇验证或限制均暂停。任务详情保留所选模式，任务的继续搜索沿用原模式；旧任务未记录模式时保持原自动评论方式。辅助“继续读取当前搜索页”使用当前表单选择。
