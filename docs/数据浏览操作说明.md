# 数据浏览操作说明

每个板块有独立页面，侧栏始终保留，向下滚动只会看到当前板块内容。总览的四张统计卡可进入对应数据页；数据来自本地数据库，不需要重新访问抖音。

- 工作台概览：`#overview`，统计卡与能力状态。
- 新建搜索：`#keyword`，搜索表单、辅助读取入口、导入和本次搜索进度；点击“查看本次搜索结果”进入详情。
- 累计任务、已存视频、去重用户、已存评论：分别为 `#tasks`、`#videos`、`#users`、`#comments`。
- 任务日志：`#task-logs`，只显示最近运行日志。
- 支持直接打开地址、刷新及浏览器前进后退；任务详情地址携带任务编号。
- 筛选和目录列表页码按板块独立保存于当前浏览器标签页会话。返回列表、切换板块后回来或刷新可恢复；关闭标签页后不保证保留。

| 入口 | 查看方式 |
|---|---|
| 累计任务 | 按执行时间倒序显示任务、状态及视频/评论/用户数量；点击进入当次任务详情 |
| 已存视频 | 按来源任务分组，显示该次执行时间和找到的视频；展开后点视频进入评论详情 |
| 去重用户 | 按视频列出评论用户；同一用户跨视频可重复展示，全局按来源和用户编号去重 |
| 已存评论 | 按视频列出主评论与回复，显示作者及页面提供的发表时间；每组每页 100 条 |

支持按任务关键词、执行日期、来源任务及视频筛选。任务/视频分组每页 20 组，旧任务不会因为超过 100 条而无法查看。返回列表保留当前筛选和列表页码。

## 视频详情

- 原先的“用户／视频／评论”并列标签已移除。列表中点击视频后进入独立评论详情，点击“返回视频列表”回到列表。
- 优先显示所选任务自己的评论快照；从仅含视频的搜索任务进入时，可展示此视频的独立读取记录，并明确标注评论来源任务和时间。
- 没有已保存评论时，需要明确点击“读取此视频评论”才启动读取。核对已有记录失败时先重试，不把失败当作没有记录。
- 保留每批 100 条主评论、分页、继续读取、暂停和所选评论的回复读取。主评论到底不代表所有回复都已读取。
- 点评论或回复的作者，打开用户侧栏。可查看该视频或所有涉及视频的最新已存评论。关闭侧栏保留原评论页的位置。
- “导出结果”导出当次任务；“导出本视频评论（含已存回复）”导出评论读取任务。若导入任务包含多个视频，该任务导出仍包含完整快照。

## 视频信息与排序

- 视频行显示点赞、评论、收藏、分享、播放、弹幕六项；点击视频查看作者主页、发布时间、时长、视频编号和信息读取时间。标题仍单行省略。
- 列表上方选择排序指标与升序/降序。另支持发布时间、时长、信息读取时间、标题、作者和原搜索顺序。仅对当前任务或分组已保存的视频排序，不影响抖音页面的搜索排序；并列值保留原顺序，缺失值始终排在末尾。
- 搜索先保存卡片可见信息，通常只有点赞、时长等。需要更多信息时点击“补充本任务视频信息”；也可点击“选择”勾选若干视频后“补充视频信息”，或在单个视频详情补充。每批最多 100 个，逐条打开正常视频页面；新任务展示进度并可暂停，原搜索快照保留。
- `—` 表示页面未提供或尚未读取，真实数字 `0` 单独显示；`≈` 表示页面使用万、亿等约数。悬停指标可看原文和各自采集时间。页面变化导致无法识别时保留缺失；旧指标若保留，仍保留它自己的旧时间。
- 评论量是页面展示的评论计数，不是本地已存评论数量。播放量、弹幕数不一定公开；本轮真实页面已验证点赞、评论、收藏、分享，未验证真实播放/弹幕数。作者从明确作者区域读取，不用标题中的 @提及代替。
- 补充信息需要浏览器空闲；遇到登录、验证、页面错位会暂停。已取得结果保留，未处理视频显示等待读取；没有取得任何计数时标为部分结果。不会自动重试或绕过验证。
- CSV/JSON 导出包含保存的信息；CSV 的 metrics 列为含原文、数值、时间的 JSON。

## 时间与历史口径

任务执行时间来自任务账本；评论发表时间只使用页面提供的 create_time，缺失显示“未提供”。不使用采集时间冒充发表时间。

不筛选任务时，用户及评论目录展示最新已存版本，并列出相关任务；筛选任务或时间范围时，使用该范围内的任务快照，同一评论取范围内最近任务的版本。用户侧栏明确展示跨任务的最新已存评论。

历史独立读取任务不一定记录了它由哪次搜索触发；界面将其标为独立读取记录，不猜测父任务。完整数据目录当前在本地构建，适合本原型的数据规模；本轮未做大规模数据压力测试。


## 搜索反馈与交互

- 点击“开始网页读取”后，按钮立即显示“正在提交”；请求确认后显示“正在读取”。读取中不允许再次提交或同时执行其他网页读取。
- 按钮下方直接显示本次搜索状态、任务说明及实际已保存视频数量。进度条表示收集数量相对最多 100 个的比例，不代表平台一定能提供 100 个视频。
- 读取过程中可以查看已存结果或点击“暂停读取”。暂停失败或状态更新中断会明确提示，先核对状态再继续。
- 登录、验证、部分结果、完成和失败分别显示提示；所有数据仍以本地任务记录为准。
- 辅助读取、指定视频链接和导入入口收在“辅助读取与导入”中，点击展开。
- 当前标签页刷新后保留搜索关键词和最近一次搜索记录。
- 页面和详情采用约 0.2 秒的轻微淡入，按钮有按压反馈，卡片悬停轻微浮起，用户侧栏滑入；开启系统“减少动态效果”时关闭动画。


## 删除本地记录

任务、视频、用户、评论及日志行提供“删除”按钮。搜索页的本次进度卡在受阻、失败或已结束时也可删除对应任务。

| 删除对象 | 影响范围 |
|---|---|
| 任务 | 删除该任务及日志、任务专属视频/评论/用户，保留其他任务共用的数据 |
| 视频 | 从所有本地任务删除该来源的视频、关联评论及不再被引用的用户 |
| 用户 | 从所有本地任务删除该来源的用户、该用户评论及关联回复 |
| 评论 | 从所有本地任务删除该来源的评论；主评论连同已保存回复一起删除 |
| 日志 | 只删除选中的本地日志 |

点击后先核对影响数量，点击“取消”不改变数据；“确认删除”无法撤销。网页来源和导入来源各自独立。操作仅影响本地数据库，不删除抖音平台内容。

相关任务正在执行时不允许删除，需要先暂停。确认期间数据变化会提示重新核对。删除结果未确认时先核对列表，不自动重试。

受影响任务的旧评论批次将停止续读，避免删除的数据被旧批次写回；可以新建任务重新读取。删除后统计、列表、筛选选项及已打开的本次进度会刷新。诊断截图属于单独的本机排错文件，本次删除功能不清理这些文件。


## 批量选择与删除

- 累计任务：勾选行首复选框，或“全选当前页”（每页 20 条）。运行中任务不可勾选。
- 已存视频：展开任务分组后，勾选视频或“全选本组视频”。
- 去重用户、已存评论：展开视频分组后，勾选记录或“全选本组当前页”（每页最多 100 条）。
- 任务日志：支持勾选和全选当前显示的日志，跳过运行中任务的日志。
- 已选记录旁显示数量；可“取消选择”，或点击“批量删除”。弹窗列出所选名称和去重后的实际影响数量。
- 切换分页、筛选或板块会清空选择；不会跨页累积，也不会把其他折叠分组一起选中。
- 批量删除一次统一计算和提交，不是逐条删除。如果任何一项不存在、涉及运行中任务或确认期间数据变化，整批不执行，需要重新核对。
- 同一实体在多个任务出现、主评论与回复同时选中时，影响数量不会重复计算；仍按来源区分网页与导入数据。

新增独立页面 `#account-actions`。账号操作不属于数据浏览或删除操作，需填写单个测试对象并逐次明确确认。流程及真实网页尚待验证的范围见《账号操作说明.md》。


## 勾选后的批量操作（2026-09-10 更新）

任务、视频、用户、评论、日志列表均已移除每条记录的删除图标。先勾选记录，再在工具栏中操作；只删除一条时也使用同一方式。新建搜索页“本次搜索进度”的清除入口仍保留。

- **导出 CSV**：下载所选记录的数据表，用 Excel 等工具查看；中文使用 UTF-8 BOM，公式样式文本按纯文本输出。
- **导出 JSON**：下载所选记录的结构化数据。选中任务时包含该任务保存的视频、评论、用户和日志。
- **批量下载视频**：仅在视频工具栏出现，一次最多 100 条；逐条打开对应抖音视频，使用页面正常提供的下载入口。它与导出视频信息是两项独立操作。
- **批量删除**：仍先展示影响范围，再确认提交。运行中的任务需先停止；切换筛选或分页后会清空勾选。

任务视频分组导出的是该任务当时保存的视频快照。用户、评论目录按所选 ID 导出本地最新记录，并附带来源任务编号。导出不会继续向抖音采集新内容。

视频页上方“视频下载”显示最近 20 个下载批次；每条会显示下载中、已下载、不可下载、失败、验证受阻或未执行的原因。已成功的视频可通过“保存视频 ZIP”下载，ZIP 内有视频文件和 results.json 清单。没有成功的视频时不提供空 ZIP。下载保留在 learning_data/downloads，下次打开页面仍可查看；批量删除数据库记录不删除已下载文件。

“停止下载”在当前文件处理结束后停止后续视频。服务重启会标记中断，不自动重新下载。页面要求登录、验证码或限制访问时会暂停整个批次，不绕过限制；没有可识别下载入口时明确标记，不将页面链接或数据 JSON 冒充视频文件。

**验证范围**：本地浏览器样例已验证视频文件保存、ZIP、失败状态及验证暂停；真实抖音下载入口仍待账号页面验证，不能保证所有视频都能下载。


## 搜索不足 100 条时（2026-09-10 更新）

新搜索和继续读取均先确认“视频”分类。搜索会滚动结果容器，保留已识别的视频，并在页面等待时显示已保存数量与等待秒数。

- **视频搜索页已到底**：在结果卡片外、可见页尾连续两次读到明确的结束提示；保留实际数量。100 是上限，不必重复读取同一页。
- **等待新结果超时，已保留数据**：连续 30 秒没有新视频，或本次读取达到 150 秒时间上限；这不代表平台已无更多结果。可检查页面后继续读取。
- **需要登录 / 验证**：暂停并等待本人处理，不自动绕过。
- **需要核对页面**：未能确认视频分类或页面没有可识别结果，不能当作零结果成功。

图文和相关搜索仍不会被凑进视频数量。页面结束提示即使出现在视频标题里，也不会据此判定到底。旧任务保留原来的状态与提示，不会改写历史。
# 浏览器画面与紧凑布局（2026-09-10）

- 任务、搜索、视频/评论和账号页面右侧增加“执行浏览器”。显示本工具浏览器的当前画面，不回放所选历史任务，也不会因为查看预览自动开始任务。
- 任务运行时画面约每 1–2 秒更新；页面加载或浏览器繁忙时可能延迟，会显示最后更新时间。断开时明确保留最后画面，不伪装成仍在实时更新。
- 点“放大”查看完整画面，按 Escape 关闭；点“操作浏览器”切到原浏览器完成登录、验证码或手工操作。预览画面本身不接收网页点击或输入。
- 点“收起浏览器”让数据区域占满宽度；停止观看后自动停止持续取图。预览只保存在内存，接口禁止缓存，不写入导出或发行包。
- 侧栏、顶部、标题、卡片和数据列表改为紧凑尺寸；保留错误、进度、数据来源和必要操作确认。窗口宽度大于 900px 时左右分栏，更窄时上下排列。
# 按需选择记录

任务、视频、用户、评论和日志默认不显示勾选框。点击列表上方“选择”进入批量模式，再勾选记录或全选，执行导出、下载或删除。点击“取消选择”会清空勾选并隐藏勾选框；切换分页、筛选或板块后也需要重新进入选择模式。正在执行的任务仍不可选中删除。

## 搜索后自动读取评论

新搜索和继续搜索现在自动串联：先收集视频，再逐条读取每个视频首批最多100条主评论，并补充可识别的视频信息。主任务累计展示视频、评论、去重用户和当前视频进度；单视频评论批次另存以支持下一批100条与回复读取，点击主任务的视频直接使用对应评论批次。

搜索不足目标但已有结果时会继续处理这些结果。普通部分评论结果保留后继续下一个视频；明确图文页跳过。登录、验证码、页面对象不符或超时会停止，不自动重试。暂停主任务会停止后续视频；这不保证每条都能取得100条或全部评论。

累计任务、已存视频、去重用户、已存评论的“选择”统一在标题右上角。进入后各分组显示勾选、全选和批量操作；取消后清空选择并隐藏勾选框，主列表筛选与翻页改变范围时退出选择。

## 统一批量操作（最新）

四个数据板块右上角点“选择”后，顶部只有一个批量操作栏，显示全选当前页、已选数量、导出和删除。视频还支持批量下载视频文件；没有平台下载入口仍显示不可下载。视频、用户、评论在选择模式平铺去重后的记录，每页最多100条，不再需要进入各分组找操作。取消后回到原分组浏览。选择模式翻页清空勾选，主目录筛选/翻页退出选择。

筛选到单个来源任务时导出该任务快照；未指定单个任务时沿用最新已存记录导出。删除仍是删除本地记录，确认前展示影响范围；导出和选择不会自动联系用户。

## 通用业务目标配置

在“新建搜索”顶部选择业务目标，展开“新建或编辑配置”填写名称、目标、搜索关键词（每行一个）、纳入条件和排除条件。保存并使用后默认填入第一条关键词，仍可修改本次搜索词，不会自动对全部关键词发起搜索。可保存多套配置，编辑后需重新保存才应用；删除前需确认。

任务创建时保存配置快照，任务详情可展开查看。之后修改或删除配置不影响旧任务。当前阶段只保存条件，尚未自动执行需求识别或客户筛选；不使用配置时保留原来的搜索方式。配置保存在本机数据库，不包含在发行包。
