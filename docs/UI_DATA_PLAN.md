# 数据入口与层级查看实施计划

目标：执行用户已确认的两项改造，四张卡与侧栏共用任务、视频、用户、评论入口；取消并列数据标签。

1. 增加只读数据目录：全部非模拟任务摘要、视频来源快照、去重用户与评论。任务筛选时读取当次快照，不拿后续内容替代历史记录。测试跨任务、跨视频、跨来源与超过 100 个任务。
2. 新增数据浏览组件：时间/关键词/任务/视频筛选、分页、任务详情、按视频分组及用户侧栏。复用现有评论分页与回复组件。
3. 卡片、侧栏统一切换内容；视频进入独立详情，返回保留筛选与页码；作者点击打开侧栏。只浏览历史时不发起平台操作，未读取的视频提供明确读取按钮。
4. 构建、针对性后端与界面回归、桌面/窄屏视觉验证，更新说明和交付包。

限制：不更改历史记录；不猜测评论发表时间；不接入真实关注/私信。历史独立读取任务可提供同视频已保存结果，但不伪称由某次搜索产生。

执行状态：四项已完成。相关整组 19 项测试通过，最终关联规则补充后 7 项 UI 再次通过；前端构建及桌面/窄屏验证通过。详见 EVIDENCE.md。
